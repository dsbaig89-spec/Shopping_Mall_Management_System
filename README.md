Shopping Mall Management System
A full-stack web application for managing products, inventory, and stock updates in a mall system.
->Features
-  Add new products
-  Update stock dynamically
-  Delete products
-  View all items in inventory
-  Real-time UI updates
   
Tech Stack
--> Frontend
- React.js
- Axios
- CSS
--> Backend
- Spring Boot
- REST API
-->Database
- PostgreSQL (pgAdmin)

  Project Structure
  Shopping_Mall_Management_System/
 ├── src/
 ├── public/
 ├── DSATM/
 ├── database.sql
